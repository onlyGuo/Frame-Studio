# H3 full-reference mode

Use Ref2VA when references identify reusable people, outfits, settings or objects. Keep each picture index tied to the uploaded image. Give a visible subject a stable subject ID and use that ID consistently in the shot. A picture can anchor more than one identifiable detail, and the different views in a costume sheet describe the same person. Use the associated outfit in its approved part of the action.

Only use media actually supplied by the adapter. Frame Studio currently supplies picture references. For adapters that also supply video or audio, those files have separately numbered IDs. A source video can supply motion, editing, or visual continuity. A source audio clip can supply a specific sound or voice when requested. Do not imply that a picture contains sound.

## Six sections

| Section                | Write                                                                                                                                                                                                                                              |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `subject_definitions`  | Identify the approved subject and its mapped picture. Describe relevant features and what the shot should follow. Avoid citing a generic mood image as an identity reference.                                                                      |
| `summary`              | In one short paragraph state what occurs in this clip and how the media supports the result.                                                                                                                                                       |
| `retention_analysis`   | Explain what stays constant and where it appears. A portrait or costume reference can preserve a face and clothing without importing its pose, blank background, or panel grid.                                                                    |
| `detailed_description` | Establish the style if needed, then follow the visible action and camera movement from `[Shot 1]`. Cite the corresponding subjects during their appearances. Mark only confirmed cuts with times. Position the speech placeholder in this section. |
| `overall_soundscape`   | Summarize the approved environment and physical sounds. Identify reference audio only when actually supplied.                                                                                                                                      |
| `non_diegetic_music`   | Specify approved score cues, or `N/A`.                                                                                                                                                                                                             |

## Concrete example

Suppose picture 1 contains the actual green raincoat reference and picture 2 the ferry pier. The retention section keeps the character's olive coat and hair from picture 1, and the pier's lamp placement and wet surfaces from picture 2. The action describes the character at the pier and follows the supplied movement, using the same reference labels. The clip has one person, regardless of how many poses are shown in the character reference. Use only the authorized dialogue at the approved moment.
