# 阿里云千问与万相图像

## 根据配置选择请求

- 千问和对应的新版万相用多模态消息结构，`input.messages` 中一个用户消息，内容先列实际传入的图片，再列图号映射与提示词。千问和多数新版万相走 `/services/aigc/multimodal-generation/generation`，从消息内容中的 image 得到产物。
- `wan2.6-image` 使用异步 `/services/aigc/image-generation/generation`，启用图文混排并限制输出一张图。较旧万相用 `/services/aigc/text2image/image-synthesis`，以 `input.prompt` 提交后轮询任务。万相 2.5/2.6 文生图用较大画幅以满足像素约束。
- 当前入口中，`qwen-image-3.0` 及后缀型号可随请求带最多 3 张参考图。每张不超过 10 MiB。图号必须和输入数组一致。其他型号按文生图处理，用不上参考图时不宣称已锁定身份。
- 服务和模型以创作者的就绪配置为准。令牌来自本次进程，产物只通过本机下载到工作室指定文件。

## 在工程中运行

1. 查 `read_project` 的 `cards` 或 `shots`。复用已经绑定的有效设定，不重复生成。
2. 对服饰使用同一张角色卡，指定 `cardId` 与 `outfitId`。非默认服饰可用默认服饰图作为身份参考，沿用脸、发型和体型，服饰以本次设定为准。
3. 提示固定为一张五视图设定页：正面上身、正面全身、面部特写、左侧、右侧。五格统一角色和穿搭，空白背景和均匀光，无图中文字、场景和额外人物。场景参考图独立生成，分镜底图才把出场角色放进场景。
4. 例如 `{"commands":[{"skill":"aliyun-image","cardId":"actor-01","outfitId":"travel"}]}`。收到回执后检查确实绑定了指定服饰。场景或道具用该卡的 `cardId`，分镜参考图用 `shotId`。

## 模型路由和结果位置

| 所填型号                                    | 入口                                                         | 实际输入与结果                                                                                         |
| ------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| `qwen-image-3.0` 及其后缀、其他千问图像模型 | 同步多模态 `/services/aigc/multimodal-generation/generation` | 一个用户消息，先图后文。仅 3.0 分支发送参考图。响应从 `output.choices[0].message.content` 中取 image。 |
| `wan2.6-image`                              | 异步 `/services/aigc/image-generation/generation`            | 启用图文混排，最多一张结果图。轮询成功后从消息内容取 image。                                           |
| `wan2.7-image`、对应新版 `t2i`              | 同步多模态                                                   | 文字提示作为当前入口的生成输入，按消息内容取得结果。                                                   |
| 较早万相，例如 `wan2.5-t2i-preview`         | 异步 `/services/aigc/text2image/image-synthesis`             | 从 `input.prompt` 取文字，轮询后使用 `output.results[0].url`。                                         |

## 例子 · 为同一个角色添一套服饰

建立角色「林岚」，给默认风衣绑定已验收的五视图图页，再创建码头工装。用支持参考图的千问 3.0 配置生成工装时，工作室会把默认图作为身份参考。内容中沿用脸、发型、体型，新服饰的材质与颜色取工装设定。用 `cardId` 和 `outfitId` 锁定结果。完成后回读角色的服饰，检查新增图片是否只绑到了工装。

也可以先制作场景图，再为已经引用该角色和场景的分镜生成底图。最多三张参考图。如果分镜使用了更多图片，先检查模型容量并选择符合该镜需求的生成方式。

## 调试顺序

按下生成后先核对当前选中的模型名和地域基础地址。收到 HTTP 400 时检查具体型号所属接口及图片大小。同步任务未在服务时限内完成时，检查供应商记录再重试。异步任务从原任务 ID 查询，既有图能正常复用时继续使用已绑定素材。
