# 短剧制作

1. 写分镜前，读取本集剧本、已有镜头以及工程设定卡。逐镜确认画面中可见的角色、场景和叙事道具。用上下文识别别名、简称和上一镜延续的主体。跨集、跨镜复用同一设定卡，画外音提到的人无需列为出场角色。
2. 将设定卡返回的 mention（如 `@{card:actor_id}`）写进分镜的大白话脚本，保留动作、服饰、空间位置与运镜。缺卡先创建，记录可复用的视觉特征。批量处理可用脚本遍历工程快照，把改动作为 actions 提交。
3. 检查出场卡对应的图片。优先沿用已绑定的定稿图；从素材库找到了能确定归属的图片时，将它绑定到该卡。确实缺图，使用 `run_command` 的媒体步骤，例如 `{"commands":[{"skill":"image","cardId":"actor_id"}]}`。多个镜头共享的卡只补图一次。创作者明确要求重做已有设定图时才传 regenerate。
4. 制片前，调用 read_project 的 shot_assets 检查目标镜头，结合具体缺项修复正式脚本、设定卡或图片后复查。只有画面确实无需资产，才用 edit_project 确认 shots.fields.assetFree。脚本和对白修改后重新核对。视频模型容纳不了全部参考图时，告诉创作者限制并保留原引用。
5. 一个命令组可按镜头顺序执行多个 `{"skill":"video","shotId":"…"}` 步骤，通过各步回执核对实际生成和绑定。已提交过的镜头先查其当前绑定。分镜的 referenceId 存底图，assetId 存主视频。用户明确要独立素材时选择 destination=library。
6. 粗剪可用 rough_cut 把已有视频按分镜补入剪辑台。按用户需要调整主轨、字幕与声音，回读工程检查，再通过 export_episode 输出成片。

## 对白与字幕

分镜对白写入所属镜头的 `dialogue`，包含说话人及原台词，作为表演和声音生成依据。剪辑字幕是观众在画面上实际看到的文字，应提取台词正文，清除说话人名称前缀、角色 mention、发言标签冒号和情绪动作说明。保留正文中的人名、标点、引语和原语言，多人对白按发言顺序及声音时间分条。修改字幕时保留分镜对白中的说话人信息。

例如对白“白小纯：父老乡亲们，我要去修仙了，可我舍不得你们啊。”对应字幕“父老乡亲们，我要去修仙了，可我舍不得你们啊。”。粗剪后检查时间线字幕是否仍含角色标签，逐条修订并核对显示时间。

## 服饰与五视图

- 角色卡记录跨镜稳定的脸、发型、年龄、体型和辨识特征。服饰独立记录名称、衣物款式、材质、颜色和穿戴配件。使用默认服饰作为常用形象，其他造型分别登记，不用一张图代表多身服饰。
- 角色通过 `cards.fields.outfits` 登记服饰。每项由 `id`、`name`、`notes`、`assetId` 组成；`defaultOutfitId` 必须指向其中一项，尚缺图时 `assetId` 用空串。扩充旧角色时，先把原图登记为默认服饰所用图，再给新服饰单独生成。
- `read_project` 返回 `@{card:角色ID:服饰ID}`，优先插入实际穿着的一套。仅写 `@{card:角色ID}` 时使用当前默认服饰。多个角色或同一角色换装时逐项核对，不让某个服饰借用另一套的绑定。生成指定服饰用 `run_command` 的图像步骤和 `cardId`、`outfitId`。
- 固定生成单张五视图页：正面上身、正面全身、面部特写、左侧、右侧。中性光、空白底、同一张脸和同一套服饰。镜头里出现的是其中同一个人，禁止生成五个重复人物或把设定页背景当作场景。

## 场景与道具参考图

- 场景卡生成一张横向三视图页，依次为正视图、侧视图和俯视图。三格保持同一空间结构、固定设施、材质和光照，只保留场景本身，不加入角色、无关道具、剧情动作、文字、边框、网格、水印或装饰图形。
- 道具卡生成单件道具的白底图，保留轮廓、材质、颜色和比例。不加入手部、人物、场景、其它物件、文字、边框、网格、水印或额外视图。
- 生成前检查主体、背景和构图是否干净。发现干扰元素时重新整理提示词或更换生成结果，不把问题图绑定到设定卡。

## 制片边界

- 每次制片只读取目标镜头的正式画面、对白及从该镜头引用得到的图片。把其他镜头或整集剧本留在编剧阶段。设定备注别写跨镜的演出和台词。对白只登记在所属镜头，保持说话人、语言、字句和先后顺序。对白为空时明确只有非语言声音。
- 选择视频 Skill 后用 `read_skill` 读取该 Skill 的原文。按它对时长、画幅、模式和参考图的约束准备命令参数。已存在镜头传其 `shotId`，不附加一份新的表演脚本。需要改稿时先写回指定镜头并再次检查。自定义命令使用 `STUDIO_VIDEO_PROMPT` 和 `STUDIO_REFERENCES` 作为真正的请求输入。
- 制片后检查画面、服饰、对白和说话人。有偏差只更新该镜，确认先前已提交的任务结果，再决定是否重新制作。

## 从剧本到成片的验收

| 阶段 | 留在工程里的资料                         | 检查内容                                                               |
| ---- | ---------------------------------------- | ---------------------------------------------------------------------- |
| 写作 | 分集题目、剧本正文、场次                 | 情节顺序清楚，每段对白能定位到本集实际发生的时刻。                     |
| 设定 | 角色卡、服饰、场景、道具、定稿图片       | 同一角色身份稳定，跨镜复用正确服饰；场景标明出入口、光向与地标。       |
| 分镜 | 镜头画面、对白、时长、资产标记、可选底图 | 景别与动作明确，角色服饰、场景、道具都能从脚本找到，画外音不误作出场。 |
| 制片 | 视频与原分镜绑定、已完成的生成回执       | 图片引用与预检一致，实际成片的口型和对白经核对。                       |
| 剪辑 | 主轨、入点、字幕、音轨与 MP4             | 视频顺序与本集一致，人工调整的片段保留，成片落盘后可定位。             |

## 示例 · 雾港末班船

镜头「雾中灯光」需要林岚的防雨风衣、渡口和钥匙。先用真实 ID 读取这三个设定及对应的图片。脚本写景别、抬头望向船灯的动作与侧移方向。将「林岚：要是今晚不开船，我就在这里等。」放到这一镜的对白栏。随后 `read_project` 的 `shot_assets` 应返回这套风衣和另外两张实际图片。若视频还未生成，使用能接收这三张图的已配置 Skill。视频通过检查后执行本集粗剪，确认镜头及对应字幕都在时间线里，字幕正文为「要是今晚不开船，我就在这里等。」。

## 修改后复核

换装时只改该镜的服饰引用。重录台词时只更新该镜的对白，保留已经确认的画面含义。制片前重新读取镜头与资产。遇到参考文件损坏，先恢复丢失的文件或换已登记的定稿。生成期间其他人修改了该镜时，按回执核对保留在素材库的版本，再手动选择是否绑定。
