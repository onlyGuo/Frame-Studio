# 腾讯混元图像

## 配置与任务

- 此入口对混元云 API 3.0 计算 TC3-HMAC-SHA256 请求签名。配置服务地址、SecretId、SecretKey 和地域。密钥只在授权的单次进程内使用。
- 先以 `SubmitHunyuanImageJob` 提交 `Prompt` 和 `Resolution`。用返回的 `JobId` 调用 `QueryHunyuanImageJob`。排队或处理中继续轮询；成功后取首张图片下载；其他状态按失败处理，先核查原任务。
- 此入口只使用文本提示词。保持跨服饰身份需要真实图片条件时，选能使用角色定稿图的图像模型。

## 制作与检查

1. 先读设定卡与目标服饰。已有合格图可直接复用，缺图才生成。例：`{"commands":[{"skill":"hunyuan-image","cardId":"actor-01","outfitId":"work"}]}`。
2. 为角色写脸部特征、体型、发型和该套穿搭。每套服饰生成一张五格设定页，其中正面上身、正面全身、面部特写、左侧和右侧各一次。保持人物一致，用空白背景，不加入剧情场景、其他人物、无关物件或文字。
3. 场景图写空间布局和光照，道具图写材料与形状。分镜底图按所选镜头的实际出场和构图制作。不要把以后镜头的动作或对白提供给本次生成。
4. 成功后核对图片登记目标与服饰或分镜一致。构图、人物身份或五视图缺失时，先修改该次输入或更换能传参考图的模型。

## 配置值和生成预期

- 「模型配置 → 图像生成 → 腾讯混元」填写混元云 API 基础地址、SecretId、SecretKey 和已开通的地域。SecretKey 填 API Key 栏。SecretId 是云账户凭据的一部分，两个值应成对。
- 入口调用腾讯云 API 的提交和查询动作。模型名称显示在工作室配置和结果路由中，适配器对该端点使用对应的混元动作，提交体包含 `Prompt` 和 `Resolution`。
- 使用标准 TLS 地址，部署代理应支持腾讯云签名相关头，并保留请求主体。接入密钥仅在当前命令进程中使用。

## 示例 · 给钥匙生成道具定稿

1. 在「角色与设定」中新建道具卡「黄铜钥匙」，记录椭圆手柄、氧化铜色、缺口形状。
2. 点击该卡的「生成参考图」，选混元。提示可补「单件物品的清晰轮廓，平放，柔和中性光，背景干净」。
3. 回读道具卡确认图已登记，然后在分镜大白话脚本中输入 `@` 引用它。需要在分镜里看到人物手持钥匙时，在画面正文描述动作。
4. Agent 可用对应的原生命令步骤 `{"skill":"hunyuan-image","cardId":"prop-key"}` 做相同操作。

## 排查

收到鉴权错误时确认地域、密钥组合和账号权限，服务器签名也依赖本机时间。若提交成功但没有图，检查该任务在服务侧的终态和配额。此入口用状态 1/2 表示待完成，使用状态 5 的第一张结果。当前请求只传文本。需要用现有图片固定同一角色身份时，选支持图像条件的入口。
